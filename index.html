Web Dice Roller

A simple dice-rolling simulator for a Yahtzee-style game.

Instructions

Web Dice Roller simulates rolling five six-sided dice for a Yahtzee-style game. Every random number comes from a remote Node.js server. When the page loads, the server is woken up and the dice are rolled automatically. To roll again, click the Roll Dice button or press the Enter key while it is focused. The CORS button calls a server API that does not allow other origins, so the browser blocks it.
